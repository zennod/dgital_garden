# E-MAIL
- ***==Email works on Layer 7 (APPLICATION LAYER) & Uses Layer 7 Protocol to send & receive information==.***
- Email uses SMTP to send an email AND POP3 or IMAP4 to receive email.
* * *
## SMTP
- ***==It stands for SIMPLE MAIL TRANSFER PROTOCOL.==***
- It's use to send e-mail from clients and between e-mail servers.
- SMTP works on ***==TCP PORT 25==*** by default.
- SMTPS (SIMPLE MAIL TRANSFER PROTOCOL SECURE) uses ***==TCP PORT 587 to wrap SMTP within TLS.==***
* * *
## POP3
- ***==POP3 stands for POST OFFICE PROTOCOL VERSION 3.==***
- This is a 2 way protocol which is used to receive the emails.
- It works on ***==TCP PORT 110.==***
- ***==Post Office Protocol 3 over SSL (POP3S) uses PORT 995.==***

* * *
# IMAP4 
- ***==It stands for INTERNET MESSAGE ACCESS PROTOCOL VERSION 4==***
- It's an alternative of POP3 which works on ***==TCP PORT 143.==***
- It supports synchronization of mail in multiple devices 
- IMAP4 also supports the concept of folders that you can place on the IMAP4 server to organize your e-mail.
- ***==Internet Message Access Protocol over SSL (IMAPS) & uses PORT 993.==***

# FTP 
[1. FAWN STAGE.](1.%20FAWN%20STAGE.md)
- ***==ACTIVE FTP uses TCP PORTS 21 and 20 and PASSIVE FTP uses only TCP PORT 21.==***
- ***Even though it's used today but the usernames and passwords, like with Telnet, are sent over the network in cleartext.***
>- *When your client sends an FTP request, it goes out on port 21. When your FTP server responds, however, it sends the data back using an ephemeral destination port and port 20 as a source port.*
- ***==TFTP Stands for Trivial File Transfer Protocol.==***
- *TFTP uses UDP port 69 and does not use usernames and passwords & is not secure at all.*

# HTTP 
- ***==Stands for HYPERTEXT TRANSFER PROTOCOL used by Web Server, works on PORT 80.==***
- HTTP has a general weakness in its handling of Web pages: it relays commands executed by users without reference to any commands previously executed.
* * *
* * *

# HTTPS & SSL/TLS
- ***==The secure version of HTTP is called as HTTPS ( HYPERTEXT TRANSFER PROTOCOL SECURE); Works on TCP PORT 443.==***
- *HTTPS uses Transport Layer Security(TLS) & Secure Socket Layer(SSL).*
- ***HTTP enables you to access the Web, but HTTPS gets you there securely. HTTPS uses TLS to provide the security.***
