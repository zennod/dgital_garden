# DNS 
[1. DNS](1.%20DNS.md)
[[1.0. DNS LOOKUP.canvas]]
- DNS uses 
	- ***==UDP PORT 53==***
	- ***==Sometimes TCP PORT 53==*** for zone transfer.

- The DNS is split into 2 halves: (*called as DNS server*)
	- **Resolvers** - *Query's name servers with a name to get its IP addr*.
	- **Name Servers** - *Hold the actual name & IP in DNS record in a database kind called a ZONE.*

* * *
- *The top DNS Name Servers are actually systems - that forms the **root servers (DNS ROOT)***

- ***==The Job of ROOT SERVER is to give name resolution to more-specific DNS systems.==***
