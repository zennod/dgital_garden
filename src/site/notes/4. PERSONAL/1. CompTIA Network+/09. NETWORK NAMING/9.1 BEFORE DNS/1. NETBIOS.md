# NETBIOS
 [2. DANCING STAGE.](2.%20DANCING%20STAGE.md)
- The NetBIOS USES:-
	- ***==TCP PORT 137 & 139.==***
	- ***==UDP PORT 137 & 138.==***
- ***NetBIOS only handled host names & used DNS names for the use of Internet.***
- Microsoft used another Layer 7 protocol called ***Server Message Block (SMB)*** that ran on top of NetBT ***to support sharing folders & files.***
- SMB used to share & access files & uses TCP PORT 445 by default.
