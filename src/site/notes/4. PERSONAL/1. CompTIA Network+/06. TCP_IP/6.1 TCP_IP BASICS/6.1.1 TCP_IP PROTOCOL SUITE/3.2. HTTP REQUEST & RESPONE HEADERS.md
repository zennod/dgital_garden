## HTTP GENERAL HEADERS:-
- ***Connection*** - Tells whether connection should ***close HTTP Transmission***.
- ***Content-Encoding*** - Specifies the ***type of encoding***.
- ***Content-Length*** - Specifies the ***Content Length*** 
- ***Content-Type*** - Specifies the ***content Type***.
- ***Transfer-Encoding*** - Specifies the ***encoding on the message body.***
* * *
## HTTP REQUEST HEADERS:-
- ***Accept*** - It specifies to the ***server*** which of ***content will it accept***.
- ***Accept-Encoding*** -  It specifies to the ***server*** which of ***message encoding it'll accept***.
- ***If-Modified-Since*** - Specifies when browser ***last received the resource***. If ***not modified***, the server ***will use the cached copy*** present on the clients machine.
- ***If-None-Match*** - Specifies ***entity tag***.
- ***Authorization*** - ***Submits Credentials***.
- ***Cookies*** - ***Submits cookies to the Server***.
- ***Host*** - Specifies the ***Host Name***.
- ***Origin*** - Specifies the ***Origin of the Request***.
- ***Referer*** - Specifies the ***Requestor of the URL***.
- ***User-Agent*** - Specifies the ***name of the browser*** that ***generated the request***.

## HTTP RESPONSE HEADERS:-
- ***Access-Control-Allow-Origin*** - The ***resource*** can be ***retrieved via the cross-domain*** [*Ability to Transfer information between 2 or more security domains.*]
- ***Cache-Control*** - Passes ***caching directive*** to the ***browse***.
- ***Pragma*** - Passes ***caching directive*** to the ***browser***.
- ***ETag*** - Specifies an ***Entity Tag***.
- ***Expires*** - How long the ***contents of the message body are valid***.
- ***Location*** - Used in ***Redirection of Responses (3xx)***.
- ***Server*** - ***Name of the Web Server Software***.
- ***Set-Cookies*** - ***Issues Cookies***.
- ***WWW-Authenticate*** - Details of the ***type*** of the ***authentication supported*** 
- ***X-Frame-Options*** - How ***response*** may be ***loaded*** within ***browser frame***
