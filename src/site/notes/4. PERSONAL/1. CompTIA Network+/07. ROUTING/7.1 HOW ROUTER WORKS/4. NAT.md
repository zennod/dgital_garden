- ## Stands for NETWORK ADDRESS TRANSLATION.
- ## *Its a Technology feature to add core capability of routing.*
* * *
- ==NAT replaces the ***source IP address of a computer (Private IP Address) with source IP address of the outside router (Public IP address)*** ; When the NAT sees the outgoing packet.== 
* * *
## Port Address Translation (PAT) - 
- ==PAT helps to connect to the internet through one or more public IP addresses.==
- ==PAT allows us to not use legit Internet IP addresses.==
- ***PAT uses port numbers to map traffic from specific machines in the network.***

![Screenshot (450) 1.png](/img/user/_resources/Screenshot%20(450)%201.png)

- *When a session starts with between internal & external machine, such as web browser accessing web site.*
- *The source & destination IP addresses and Port number for the TCP segment or UDP datagram are recorded in the NAT device’s translation table.*
- ==*Then Private IP address & the Port no. is swapped with the Public IP address & Unique Port no.*==

- ==*When receiving system sends the packet back, it reverses the IP addresses & the Ports.*==

# Dynamic NAT (DNAT)
- Many computer share a pool of IP addresses. 
- As the LAN traffic uses the private IP addresses. 
- ==*So, when the request is outside the network then the NAT gives out addresses out of its pool for that communication.*==
- ***Dynamic NAT is also called pooled NAT.***
* * *
# Port Forwarding - 
- ==*If a user outside the network wants to access the internal computer/service, that's where the Port Forwarding comes in handy*.==
- ***To use Port Forwarding you need to configure it***. 
- **When you want to access non-default port** - *To access the internal Web server from outside the network you need to change the URL by specifying the port request number.*
