# ROUTERS(ACCESS PT.)
- A router is any piece of hardware or software that forwards packets based on their destination IP address.
-  Routers work, at the Network layer (Layer 3) of the OSI model.
- <mark style="background: #FF5582A6;"> The Home Router serves multiple functions, as a router, a switch, a WiFi, a firewall, a DHCP Server & much more.</mark>
