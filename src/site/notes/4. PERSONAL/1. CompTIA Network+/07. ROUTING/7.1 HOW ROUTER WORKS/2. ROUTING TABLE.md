## Routing begins as the packet comes into the router for handling of the packet.
* * *
1. The Router **removes any of the information of the Data link Layer** (layer 2) as it consists the **FRAME**.
2. & Queues the resulting IP packet on the basis when of it was arrived.
3. ==The Router ***checks the destination IP*** of each packet & sends the ***IP packet to the correct Port.***==
4. ==To perform ***Inspection***, the router comes with a ***ROUTING TABLE*** which ensures where to send the packet.==
5. ==This is the ***KEY to understand & control the process of the forwarding packets to their proper destination.***==

![6c77c7d34b953f971467a888f0664d42.png](/img/user/_resources/6c77c7d34b953f971467a888f0664d42.png)
- Routing Table of a HOME ROUTER.
6. The Home Router in the above image has **2 internal port** 
	- *One port to connect to the ISP; Labeled as WAN0 TYPE & eth0 Iface.*
	- *The other to connect router's built-in switch; labeled as LAN TYPE & br0 Iface*.

7.  Let's know the table briefly -
	- ***Destination*** -
		- ***Lists*** every Network ID which is directly connected to the ***router's PORT.*** 

	- ***Gateway*** - 
	 	- *The Gateway column tells the Router to which IP address the packet must be sent.*
	 	- *If the network ID is directly connected to the router, no of gateway.* 
	 	- *If no gateway needed, most routing tables put either * , 0.0.0.0, or On-link in this column.*

	- ***Genmask*** -
		- It is the ***SUBNET MASK***, which the router refers ***GENMASK***.

	- ***Flags*** - 
		- **"U"** means that the router is **UP & WORKING.**
		- **"H"** means that the router is a **HOST** 
		- **"G"** means the routers **GATEWAY.**

	- ***Metric, Ref & Use*** - 
		- The value **'0'** represent the **best route to a destination.**

	- ***Type & Iface*** - 
		- If tells the **router which port** to use & **its type of the port**.

8. The ***Router uses*** the **combination of destination & subnet mask** to ***determine the route***.

9. The router compares the destination IP address to every route listed in the table & then sends the packet out.

10. If a packet matches more than one route, the router uses the efficient route.

11. Every router has a ***DEFAULT ROUTE / 0.0.0.0*** listed. ==The Default Route is very important as it tell the router exactly what to do when it doesn't matches any other route listed.==

12. Interpreting a router.

>  **NOTE**  :  *There are two places where you’ll find routers that do not have default routes: **isolated (as in not on the Internet) internetworks**, where every router knows about every connected network, and the **monstrous “Tier One” backbone**, where you’ll find the routers that make the main connections of the Internet.*

13. Every NODE on the network has routing table.

## METRIC- 

- A Metic is a relative value that ***defines quality of a route.***
- Router knows ***more than one route*** to get a packet to its destination. 
- If a route ***goes down***, ***router uses the alternative route*** to deliver the packet.

![bdcfacc716d2cca1d44d14036170ea57.png](/img/user/_resources/bdcfacc716d2cca1d44d14036170ea57.png) 

- The ***Lowest metric always WINS***. But as soon as the ***1st route fails,*** router automatically ***changes to the alternate route*** to deliver the packet.
