## Examining the ROUTE TABLE - 

![3d9b9a4e569d81aea9702004e5732ce2.png](/img/user/_resources/3d9b9a4e569d81aea9702004e5732ce2.png)

1. First, We have the ***Default Route.*** *(Any destination address) (with any subnet mask) (forward it to my default gateway) (using my NIC) (Metric of 25 to use this route).*
2. Next, We have three lines about the ***loopback address***. 
	- First route, **any packet with a network ID of 127.0.0.0/8 will be sent to the loopback**.
	- Second, **its the loopback address.**
	- Third, **it handles the broadcast traffic for the loopback.**
3. Next, we have **Local Connection**: - 
	-	***(Any packet for the 192.168.1.0) (/24 network ID) (don’t use a gateway) (just ARP on the LAN interface to get the MAC address and send it directly to the recipient) (Metric of 291 to use this route).***
	- Next, we have **directed broadcast**, for **broadcasting on the same Network ID**.
	- ***In rare cases, you'll have more than one net ID on the same LAN as in the image.***
4. The next lines are for the ***multicast address*** range. Win & MacOS out this lines automatically. 

5. ***The bottom 2 lines with actual IP interface defines a limited broadcast (255.255.255.255)***
