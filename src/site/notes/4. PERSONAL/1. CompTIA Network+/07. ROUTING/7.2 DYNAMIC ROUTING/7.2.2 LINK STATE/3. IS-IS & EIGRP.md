# IS-IS

- The IS-IS stands for ***Intermediate State to Intermediate State.***
- **It's Extremely similar to the OSPF.**
- It has an major ***advantage of working with IPv6.***
- IS-IS is the **standard** Link State Dynamic Routing Protocol for ISPs.

***

# EIGRP

- EIGRP stands for ***Enhanced Interior Gateway Routing Protocol.***
- When RIPs wasn't efficient enough & OSPF wasn't introduced; ***Cisco introduced Interior Gateway Routing Protocol (IGRP), replaced with EIGRP.***
- EIGRP is both **DISTANCE VECTOR & LINK STATE** PROTOCOL. Acts as **Hybrid**.
- Also, called as ***ADVANCED DISTANCE VECTOR PROTOCOL.***
