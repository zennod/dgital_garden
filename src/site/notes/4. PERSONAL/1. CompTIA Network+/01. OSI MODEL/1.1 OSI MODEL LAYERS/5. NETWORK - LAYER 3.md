## At the Network layer, Layer 3, containers called packets get created and addressed from one network to another.
LINKED [OSI IN IMAGES. ](OSI%20IN%20IMAGE.md)
* * *
## TCP/IP 
- The Network Layer consist ***TCP/IP***.
- Each system has ***2 unique address, MAC(Physical) & IP (Logical) address.*** 
* * *
## IP :-
- Internet Protocol make sure's that the data reaches at the accurate informed destination. 
- This is done by assigning the each devices with the unique addresses called ***IP ADDRESSES (LOGICAL ADDRESS).***
- IP address no. ranges from ***0 to 255.***
* * *
## ROUTERS:-
- The routers connect's each of the ***subnets***. Here the subnets are the ***devices***.
- Routers uses the ip addresses to transmit data. Wireless data transmission is also possible by use of IP addresses.
* * *
## Packets Within Frame:-
- The Frame consists a block named ***'Packet Header'***.
- Inside the packet header; we've 
First, Destination IP address 
Second, Source IP address.
This enables the router to know where the data is to be sent.
![aefd975acf2bc19565af4fd21ac1867d.png](/img/user/_resources/aefd975acf2bc19565af4fd21ac1867d.png)
- Then these IP packets are handed to the NIC & adds them to the frame.
![9eb52a83ccb635c238a18879d1941542.png](/img/user/_resources/9eb52a83ccb635c238a18879d1941542.png)
- Before reaching the destination, the IP packets go through many routers.
- Each routers breakdown the IP packets, to decide where to send the data acc. to the IP address.
- The new frame type will be of the specific tech. to connects the next router.
![aee55299b0b548e2582fda16f213d54c.png](/img/user/_resources/aee55299b0b548e2582fda16f213d54c.png)
- Then the Receiving NIC removes the Ethernet frame & passes the packet to systems software.
