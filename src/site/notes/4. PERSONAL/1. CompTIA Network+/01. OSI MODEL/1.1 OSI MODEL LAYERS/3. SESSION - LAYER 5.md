## The SESSION layer verifies that one system can communicate with the another system. 
LINKED [OSI IN IMAGES. ](OSI%20IN%20IMAGE.md)
* * *
- Session Software helps in connecting application-to-application.
- The session layer initiates sessions, accepts incoming sessions, open & closes the existing sessions.
- To see all your sessions in real time; type ***netstat -a*** to view all the sessions & in linux you can use ***ss*** command.
