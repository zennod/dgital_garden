#react #reactjs
- Components is basically a **JS FUNCTION** which *returns* a **JSX** output *(i.e. in HTML format)*.

```JSX
function App(){
	return(
		<div> 
			<p>Parent DIV</p>
		</div>
	)
}
```

***
- Multiple **`<div>`** is not allowed on the same level. 
```JSX
function App() {
  return (
    <div>
      <p>Parent DIV</p>
    </div>
    <div>     </div>
  )
}
```
- To Resolve this issue we have the **FRAGMENT** - **`<> </>`** 
	- Which refers to *non-div* parent. 
```JSX 
function App() {
  return (
  <>
    <div>
      <p>Parent DIV_1</p>
    </div>
    <div>
	   <p>Parent DIV_2</p>
    </div>
   </>
  )
}
```
***
***
# USING COMPONENT 
- To use the component the method is just write the **COMPONENT NAME** as *HTML TAG*. - **`<Component_Name />`**

```JSX
function App() {
  return (
  <>
    <div>
      <p>Parent DIV_1</p>
    </div>
	<Text />
   </>
  )
}

function Text() {
	<div>
      <p>Hello World</p>
    </div>
}
```
