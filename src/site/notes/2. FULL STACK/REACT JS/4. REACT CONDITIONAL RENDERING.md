#react #reactjs #JS 

- Basically, it refers **RENDERING** according to the given **CONDITION**
- There are 2 ways to do it.
# FIRST WAY 
- General Syntax - 
	- **`{condition} ? (code_to_display) : (code_to_display)`**

```JSX 
function func_name(){
	return(
		{condition} ?(code_to_display) : (code_to_display)
	)
}
```
## EXAMPLE 
```JSX 
function App() {
  const movieNumber = 2;
  return (
    <div>
      {movieNumber === 1 ? (
        <MovieCard movie={{ title: "ABCD", release_date: "2025" }} />
      ) : (
        <MovieCard movie={{ title: "Ford VS Ferrari", release_date: "2025" }} />
      )}
    </div>
  );
}
```
***
***
# SECOND WAY 
- General Syntax - 
	- **`{condition && (code_to_display)}`**

```JSX 
function func_name(){
	return(
	{condition && (code_to_display)}
)}
```

## EXAMPLE 
```JSX 
function App(){
	return(
		<>
			{movieNumber === 1 && <MovieCard movie = {{title:"Hello", release_date:"2023"}} /> } 
		</>
)}
```
