#react #reactjs #JS #javascript 

- States is something like *saving* the input value. 
- **STATE** refers to a thing where once it's *updated*, the **COMPONENT** will *change* & *re-render* itself to show new state.[^1] 
- General Syntax - 
```JSX 
const State_Name, set_State_name = useState(default_val_of_state )
```
***
# CONNECTING STATE TO JSX CODE
- If you want to **connect** the **`useState`** to the *JSX* code 
	- Use - **`value = {State_Name}`**
- And to make the **STATE** *operational*. 
	- use the **EVENT LISTENER** - **`onChange()`** 
	- *Updating state* - **`eventListener = {(e) => Set_State_name(e.target.value) }`**
```JSX 
<div> 
	<form> 
		<input 				                    type="text"
		    placeholder="search"
            className="search-input"
            value={searchQuery} 
            onChange = {(e) => setsearchQuery(e.target.value)}
         />
	</form> 
</div>
```
***
***
- We can *set state* as per our need when the **EVENT** is triggered. 
- Just add this - **`set_State_name(value)`** 
```JSX 
const handleSearch(e){
	e.preventDefault();
	setSearchQuery("--")
}
```

# ACTUAL USE CASE
- Using STATE to display different value inside of the **COMPONENT**
- Using [[2. FULL STACK/REACT JS/4. REACT CONDITIONAL RENDERING\| CONDITIONAL RENDERING]] we can perform action 
## UPDATING ARR 
- Updating the array using **`useState`** is done as follow. 
### ADDING 
```JSX
const [data,setData] = useState([]);

const addData = (res) =>{
	setData(prev => [...prev, res]);
}
```

### REMOVING 
- The below FUNCTION will return a new array where it doesn't have the mentioned movie ID
```JSX 
const removeFromFavorites = (movieId) =>{
	setFavorites(prev => prev.filter(movie => movie.id !== movieId) )
}
```
