#java #oops #Object_Oriented_Programming 

- Wrapper meaning that it *Wraps the value of PRIMITIVE datatype in the OBJECT*. 
-  When you use the *WRAPPER CLASS* **DATATYPE**. 
	- The variable which is created turns into the **OBJECT**
- Wrapper class can store **`null`** 
	- **`Integer a = null`**
***
**`int a = 1;`** - It's stored into the *STACK Memory*.
**`Integer b = 1;`** - It's stored in the *HEAP Memory*.
****
- There are Multiple Wrapper Class - 
	1. **`Integer`**
	2. **`Float`** 
	3. **`Double`** 
	4. **`Boolean`**
	5. **`Character`**
	6. **`Short`**
	7. **`Long`** 
	8. **`Byte`**
