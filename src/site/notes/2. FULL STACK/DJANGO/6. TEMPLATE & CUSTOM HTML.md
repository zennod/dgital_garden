#django  #python 

- First, create a directory named `template` in the *app_dir*
- Again, inside the `template` dir.  
	- Create a new directory named same as the *app_name*.
- And create the **`HTML`** page. 
***
- Same as the flask you can **extend** the `base.html` page. 
```HTML 
{% extends 'main/base.html' %}
```

***
- To render the HTML Template. 
	- Use **`render(response, "template_path", {})`**
	- In the `views.py`
```Python
def index(response):
    return render(response, "main/base.html", {})

def home(response):
    return render(response, "main/home.html", {})
```
