#python #django 

## STEP 1 
- First import the **`HttpResponse`** library
```Python 
from django.http import HttpResponse`
def index(response):
    return HttpResponse("Index Page")
```
- This is how you generate the webpage in the Django.
***
## STEP 2 
- Create a new file named **`urls.py`** in the **app_folder**. 
```Python 
from django.urls import path
from . import views

# This tell us that we'll reach to the homepage if not path entered in the url
urlpatterns = [
path("", views.index, name="index" )
]
```
