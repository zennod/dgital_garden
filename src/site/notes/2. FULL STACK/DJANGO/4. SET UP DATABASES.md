# SET-UP 
## STEP 1 - 
- First, we need to make changes in the **`settings.py`** of the **project_folder**. 
- Now, in the **`INSTALLED_APPS`** add the **app** under that array. 
	- General format - `app_name.apps.AppConfig`
```Python 

INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'main.apps.MainConfig'
]
```

***
## STEP 2 
- Now after you added the **app** in the Django. 
- Next, is to **`migrate`** the **`INSTALLED APPS`**. 
- To do so, go to  **`project_dir/`** directory & run **`python manage.py migrate`**

***
# MODELS 
- The model is entity of the Database, which includes *attributes* &  *methods*.
- To access & write the models you need to go to the **`app/models.py`** file. 
- General Syntax - 
```Python 
class model_name(models.Model):
	attr_name = models.field_data_type(type_of_field)
```
- Actual - 
```Python
class ToDoList(models.Model):
    name = models.CharField(max_length=200)
    def __str__(self):
        return self.name

class Item(models.Model):
    todolist = models.ForeignKey(ToDoList, on_delete=models.CASCADE)
      text = models.CharField(max_length=300)
    complete = models.BooleanField()
    
    def __str__(self):
        return self.text
```

- Here, we add **`models.ForeignKey(ToDoList, on_delete=models.CASCADE)`** this to ensure that when a ToDoList is deleted, all the objects related to the specified model (ToDoList) are also deleted from the database.  
- If the a Todo item is deleted then the ToDoList is also deleted. 

***
#  ACTIVATING TABLE
- To activate the changes that we made we need to run the below command. 
- It's similar to the *GitHub version controlling*
```Python 
python manage.py makemigrations app_name
```
- After this is done use - 
```Python 
python manage.py migrate
```
