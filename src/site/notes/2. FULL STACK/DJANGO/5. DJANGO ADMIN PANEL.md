#django #python 
- Admin panel is used to access all the information related to the website, database & other activities. 
- To activate the **ADMIN PANEL** use the below command. 
```Python 
python manage.py createsuperuser
```
***
***
- To add the database's you create. Go to the **`app_dir/admin.py`**. And add the database using the below code. 
```Python
# admin.site.register(DB_name)
admin.site.register(ToDoList)
```
