# GENERIC CLASS
- The below is the **GENERIC TYPE CLASS**
	- The *`convention`* says that to use only **`T`** for *defining Type* 
	- *`Naming Convention`* - 
		- **`T`** - *TYPE*
		- **`E`** - *ELEMENT* (Used in Collection)
		- **`K`** - *KEY* (Used in Maps)
		- **`V`** - *VALUE* (Used in Maps)
		- **`N`** - *NUMBER*
```JAVA
class ClassName<T> {
	private T value; 
	
	public T getValue(){
		return value;
	}
	
	public void setValue(T value){
		this.value = value;
	}
}

//main file 
public class Main{
	public static void main(String[] args){
		ClassName<Integer> var_name = new ClassName<>(); // Type Safe
	}
}
```
