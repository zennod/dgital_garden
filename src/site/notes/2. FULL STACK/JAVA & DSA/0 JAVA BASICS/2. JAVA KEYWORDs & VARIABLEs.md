# JAVA KEYWORDS 
- *PRIMITIVES DATA TYPES* : **BYTE**, **SHORT**, **INT**, **LONG**, **FLOAT**, **DOUBLE**,**CHAR**, **BOOLEAN**
- *FLOW CONTROL* : **IF**, **ELSE**, **FOR**, **DO**, **WHILE**, **SWITCH**, **CASE** ,**DEFAULT**, **BREAK**, **CONTINUE**,**RETURN**
- *EXCEPTION HANDLING* : **TRY**, **CATCH**, **FINALLY**, **THROW** / **THROWS**,**ASSERT**
- *MODIFIERS* : **PUBLIC**, **PRIVATE**, **PROTECTED**, **FINAL**, **STATIC**, **NATIVE**, **ABSTRACT**, **SYNCHRONIZED**, **TRANSIENT**, **VOLATILE**, **STRICTFP**
- *CLASS RELATED* : **CLASS**, **INTERFACE**, **PACKAGE**, **EXTENDS**, **IMPLEMENTS**, **IMPORT**
- *OBJECT RELATED* : **NEW**, **INSTANCEOF**, **SUPER**, **THIS**
- *LITERALS* : **TRUE**, **FALSE**, **NULL**
- *OTHERS* : **VOID**, **ENUM**

# VARIABLEs 
1. **PRIMITIVE VARIABLES** 
	- These are the basic variables - Such as - int, double, float ,long, short, char, String, etc 
2. **REFERENCE VARIABLE** 
	- These are the OBJECTs which can be used as the variables.
	- *Reference Variable* always starts with **UPPERCASE** 
	- Also, it has *inbuilt methods*
		- **`String`**, **`Date`**, etc.
```Java 
Date date = new Date();
String name = new String("Hello");
System.out.print(date)
System.out.print(name.charAt(0)) //H
```
