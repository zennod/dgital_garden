#java #DSA #Object_Oriented_Programming

- It's just a upgrade version of *FOR LOOP*.
```Java
for(datatype index_var_name : var_name){
	block_of_code
}
```

# EXAMPLE 
```Java
for (int number : numbers){
	System.out.println(number);
}
```

```Java
for (String name: numbers){
	System.out.println(number);
}
```
