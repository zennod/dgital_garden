# DO-WHILE 
- The Do-While loop will **first run** the *block of code*.
- Then *check the Condition*.
```Java
initialization
do{
	block_of_code
	updation
} while (condition)
```

```Java 
int i = 100;
do{
	System.out.println(i);
	i++;
}while(i<=50);
```
- It'll print **`100`** *first* and then after checking the condition.
- The compiler will find that the condition is **`false`**.
- Therefore, it'll break the loop.

# WHILE 
- The while loop will **FIRST** check the condition then run the **LOOP**.
```Java
initialization
while(condition){
	block_of_code
	updation
}
```
