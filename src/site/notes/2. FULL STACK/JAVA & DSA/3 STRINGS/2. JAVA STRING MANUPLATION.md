# Pretty Printing
- To use Placeholders we use **`System.out.printf()`** 
- There are different kind of Placeholders involved in java.
**`%c`** - Character
**`%d`** - Decimal number (base 10)
**`%e`** - Exponential floating-point number
**`%f`** - Floating-point number
**`%i`** - Integer (base 10)
**`%o`** - Octal number (base 8)
**`%s`** - String
**`%u`** - Unsigned decimal (integer) number
**`%x`** - Hexadecimal number (base 16)
**`%t`** - Date/time
**`%n`** - Newline
```Java
System.out.printf("Hello, I am %s.", "Xerxeus");
//Output
Hello I am Xexeus.
```

# Index & CharAt

# compareTo 
- **`compareTo`** compare the **ASCII value** of the first character *(It can be Capital / Small)* of the String.
- If the *Strings are same.*
	- It'll compare *till the end* of the string. & Output will be **0**.
- If *Strings are not same*. 
	- It'll **Stop** and **Subtract** the *ASCII value* of character & print the *output in integer*.
- To Omit AlphaCase use **`compareToIgnoreCase `**
```Java
String str1 = "remote";
String str2 = "ramote";
System.out.println(str2.compareTo(str1)); //-4
// 97 - 101 = -4
```
