#DSA 
- It creates **ONE OBJECT** and the *changes are made to that OBJECT only.*
- *STRINGBUILDER is separate CLASS.*
- STRINGBUILDER are **MUTABLE**.
```Java
StringBuilder bul = new StringBuilder();
for (int i = 0; i<26; i++){
	char ch = (char)('a'+i);
	bul.append(ch);
}
System.out.println(bul);
```

```JAVA
public String convertToTitle(int col) {
	StringBuilder sb = new StringBuilder();
	while(col>0){
		col--;
		int rem = col%26;
		sb.append((char)(rem + 'A'));
		col/=26;
	}
	return sb.reverse().toString();
}
```
