# 1. STRING POOL
- **STRING POOL** is area where **STRING LITERALs** (*`String name = "Java"`*) are stored to *save memory & performance.* 
- If the value of String **exists** in the String Pool - 
	- Java reuses it & 
	- **`String var`** points to the same *MEMORY LOCATION*
	- Resulting **`true`** as output.
-   If the value of String **doesn't exists** in the String Pool -
- Java *create* a **NEW STRING** & saves it in the String Pool.

```Java 
String a = "Xerxeus";
String b = "Xerxeus";
System.out.println(a==b) // true 
// It'll Point to the same String created.
```

# HEAP MEMORY
- Use of **`new`** keyword.
```Java
String a = new String("Xerxeus");
String b = new String("Xerxeus");
sout(a==b); // false
```
- *The string **`a`** & **`b`** is stored in the Heap Memory* 
- The Output is *FALSE* because the **`ref_variable`** is *not pointing* to the same value.
- Meaning the **`String a`** is stored at **DIFFERENT MEMORY ADDRESS** compare to **`String b`** **MEMORY ADDRESS**.

# 2. IMMUTABILITY
- String are **IMMUTABLE** in *NATURE* as it's an **OBJECT** & also for security reason.
- So if a String is created & *you want to change it make an new Object.*
```Java
String a = "Xerxeus";
sout(a);
String a = "Borth";

//Output
Xerxeus
Borth
```

# .equals
- It'll only check the **value of string** *(Character by Character)* & not the reference variable.
```Java
String a = new String("Xerxeus");
String b = new String("xerxeus");
sout(a.equals(b)); // false

// To Omit the AlphaCase
sout(a.equalsIgnoreCase(b)); //true
```

# .toCharArray
- To convert the String to Character you can use. **`toCharArray()`**.
```Java
 public static void main(String[] args) {  
    String s = "Java";
    char[] c = s.toCharArray();
    System.out.println("" + Arrays.toString(c));
```
