- Linear means the *TIME GROWS with the INPUTs*.
- The Searching can be done Linearly *(i.e. One after the Other OR From START To END)*
- The Worst case Time Complexity of linear search is *BIG* **O(N)** *(BIG O Means it can't go worst than LINEAR)*
- The Best case Time Complexity of Linear Search is *BIG* **O(1)**
