#java #java_multithreading #Object_Oriented_Programming 

- **`start()`** - *Starts* the thread for execution. JVM calls **`run()`**
- **`run()`** - When a Thread starts the **`run()`** method is *invoked*. Basically the *logic runs*. 
- **`sleep(milisec)`** - Causes *delay/sleep* in executing the thread.
- **`join()`** - Waits for the **PRESENT** thread to **DIE**.
	- When one thread calls the `join()` method of *another thread*, it **pauses** the execution of the current thread until the thread being joined has completed its execution.
- **`setPriority(int newPriority)`** - Changes the *Priority* of thread. 
	- **`Thread.MIN_PRIORITY`** (1)
	- **`Thread.NORM_PRIORITY)`** (5)
	- **`Thread.MAX_PRIORITY`** (10)
