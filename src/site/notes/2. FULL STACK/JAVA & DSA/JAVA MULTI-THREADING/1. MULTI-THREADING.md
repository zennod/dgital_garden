# THREAD 
- **THREAD** is a *Smallest Unit* of execution *within* a **PROCESS**. 
- **PROCESS** can have **MULTIPLE THREADs**, which share SAME RESOURCEs
- Threads work **INDEPENDANTLY**
## EXAMPLE 
- *Google Chrome* 
	- Uses *Multiple Threads* for different **TABS**
***
***
# MULTI-THREADING
- Refers to the *ability to execute multiple threads within a single process simultaneously*. 
- MULTI-THREADING enhances the **efficiency** of *multi-tasking* & *CPU* by breaking down a *BIGGER TASK* into **SMALLER SUB - TASK** or **THREADS**.
- Also, exception *won't interrupt* the other threads
## SINGLE CORE SYSTEM 
- Both THREADs & PROCESSEs are managed by OS scheduler.
	- Via **TIME SLICING** (*Divides the CPU time into smaller intervals*)
	- & **CONTEXT SWITCHING** (*switching between task/process/thread*)
- *Java in Single Core Environment,* Multi-Threading is *managed* by **JVM** & **OS**, which switches between threads
## MULTI-CORE SYSTEM 
- Both THREADs & PROCESSEs run in **PARALLEL** on **DIFFERENT COREs**.
