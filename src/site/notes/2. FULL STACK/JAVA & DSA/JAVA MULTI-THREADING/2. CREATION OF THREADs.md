#java #java_multithreading #Object_Oriented_Programming 

- When a JAVA programs run, **ONE thread** begins running known as **MAIN THREAD** 
	- The *MAIN THREAD* is responsible for the *execution* of the **MAIN METHOD.**
# CREATION of THREAD 
There are 2 main ways to create **THREAD** 
1. **`extends`** **THREADS CLASS**
2. **`implements`** **RUNNABLE CLASS**
## METHOD 1 - 
1. Create a new **CLASS** & *extend* the class with the **THREAD** class. 
2. Next, you need to **`Override`** the **`run()`** method.
3. To run the method using **THREAD** you need to use **`start()`** method.
4. If you use **`run()`** to *start* the **THREAD**, it would do it *one by one*
```Java 
public class multhread extends Thread{
	@Override
	public void run(){
		block_of_code
	}
}
```

```Java
// Main Class 

public static void main(String[] args){

	cls_name obj_var1 = new cls_construct();  // Thread 1
	method.start();
	cls_name obj_var2 = new cls_construct();  // Thread 2
	method.start();
}
```
### EXAMPLE 
```Java
public class multhread extends Thread{
	@Override
	public void run(){
			for(int i=0, i<=5; i++){
				System.out.println(i);
			try{
				Thread.sleep(1000);
			}
			catch(InterrupedException e){
			}
		}
	}
}
```

```Java
// Main Class 

public static void main(String[] args){

	multhread thread1 = new multhread(); 
	multhread thread2 = new multhread();
	
	thread1.start();
	thread2.start();
}
```

- You use loops to run multiple threads at the same time
```Java
public static void main(String[] args){
	for(int i=0; i<=5; i++){
		multhread thread1 = new multhread(); 
		thread1.start();
	}
}
```

## METHOD 2 - PEFERRED
1. Create a new **CLASS** & *IMPLEMENT* the class with the **RUNNABLE** class. 
2. Every other thing is SAME. 
3. Only thing need to be ADDED & changed is the **`start()`** method. 
	- Since, we aren't extending the **`Thread`** class. 
	- We need to create a **`Thread`** *OBJECT* and pass the **OBJECT** of the *new class*
```Java
Thread myThread = new Thread(thread1)
```

```Java 
public class multhread implements Thread{
	@Override
	public void run(){
			for(int i=0, i<=5; i++){
				System.out.println(i);
			try{
				Thread.sleep(1000);
			}
			catch(InterrupedException e){
			}
		}
	}
}

-----------------------------------------------------
// Main Class 

public static void main(String[] args){
	for(int i=0; i<=5; i++){
		multhread thread1 = new multhread(); 
		Thread myThread = new Thread(thread1);
		myThread.start();
	}
}
```
