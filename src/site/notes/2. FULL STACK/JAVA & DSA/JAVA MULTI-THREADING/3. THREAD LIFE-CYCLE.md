#java #java_multithreading #Object_Oriented_Programming 
# LIFE-CYCLE 
- The *THREAD LIFE-CYCLE* consists of several **STATES**. 
- The *THREAD undergoes* through these STATES during **EXECUTION**
# STATES 
1. **NEW** 
	- THREAD is **CREATED** but not *STARTED*
	- `multhread thread1 = new multhread();`
2. **RUNNABLE**
	- THREAD *STARTS* & become **RUNNABLE**. Ready to *run* & *waits* for *CPU TIME*. 
	- `thread1.start();`
3. **RUNNING**
	- *Executing* & Running state
	- `public void run()`
4. **BLOCKED / WAITING**
	- Thread *WAITs* for *RESOURCEs* 
5. **TERMINATED**
	- *FINISHES EXECUTION* & gets terminated
