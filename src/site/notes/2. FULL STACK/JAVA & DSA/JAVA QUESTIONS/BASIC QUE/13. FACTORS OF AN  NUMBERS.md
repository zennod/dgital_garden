- Those number which are Fully Divisible (i.e. Gives the remainder 0)

```Java
public static void fact(){  
    Scanner input = new Scanner(System.in);  
    System.out.print("Enter a Number: ");  
    int num = input.nextInt();  
  
    for (int i = 1; i <=num ; i++) {  
        if (num%i==0){  
            System.out.print(i+",");  
        }  
    }}
```
