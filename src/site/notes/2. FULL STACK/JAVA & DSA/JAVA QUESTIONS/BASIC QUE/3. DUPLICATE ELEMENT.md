## SET 
```Java
static void removeDuplicate(){  
	Scanner input = new Scanner(System.in);  
	System.out.print("Enter the Range of the Array: ");  

	int arr_range = input.nextInt();  
	int[] arr = new int[arr_range];  

	System.out.println("Enter the elements");  
	for (int i = 0; i < arr_range ; i++) {  
		arr[i] = input.nextInt();  
	}  

// Main logic
	Set<Integer> seen = new HashSet<>();  
	Set<Integer> duplicates = new HashSet<>();  

	for (int ele : arr){  
		if (!seen.add(ele)){  
			duplicates.add(ele);  
		}  
	}        if (duplicates.isEmpty()){  
		System.out.println("Not Duplicate found.");  
	}  
	else {  
		System.out.println("The duplicates are: " + duplicates);  
	}  
}
```

# 2. STRING
```java
public static void duplicateElementOfString() {  
Scanner sc = new Scanner(System.in);  
System.out.println("Enter The Array range: ");  
int num = sc.nextInt();  

String[] arrNames = new String[num];  

for (int i = 0; i < num; i++) {  
	arrNames[i] = sc.nextLine();  
}  

//1. Comparing elements (O n*n)  
for (int i = 0; i < arrNames.length; i++) {  
	for (int j = i + 1; j < arrNames.length; j++) {  
		if (arrNames[i].equals(arrNames[j])) {  
			System.out.println("Duplicate Element: " + arrNames[i]);  
			}  
		}      
	}   
}  
```
