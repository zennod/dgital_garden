# Reversal
```Java
public static void main(String[] args) {  
    int[] arr = {1,1,0};  
    int[] temp = new int[arr.length];  
    int len = arr.length;  
    for (int i = 0; i < arr.length ; i++) {  
        temp[len-1] = arr[i];  
        len = len -1;  
    }  
    System.out.println(Arrays.toString(temp));  
}
```
