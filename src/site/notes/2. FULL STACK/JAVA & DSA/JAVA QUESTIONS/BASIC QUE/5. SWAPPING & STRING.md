# 1. INTEGER SWAP W/O 3rd VARIABLE
```Java
public static void swapTwoVar(){  
	Scanner sc = new Scanner(System.in);  
	System.out.println("Enter the 1st Variable: ");  
   int x = sc.nextInt();  
	System.out.println("Enter the 2nd Variable: ");  
   int y = sc.nextInt();  
  
// 1. Using third var  
	int t;  
	t = x;  
	x = y;  
	y = t ;  

// 2. Without Third Variable using + operator  
	x = x + y;  
	y = x - y;  
	x = x - y;  

// 3. Without Third Variable using * operator  
	x = x * y;  
	y = x / y;  
	x = x / y;  

// 4. Without Third Variable using XOR(^) operator (bitwise conversion)  
	x = x ^ y;  
	y = x ^ y;  
	x = x ^ y;  
  
	System.out.println("The new swapped 1st var: " + x );  
	System.out.print("The new swapped 2nd var: " + y );
    }
```

# 2. STRING SWAP W/O THIRD VARIABLE
```Java
public static void swapString(){  
Scanner sc = new Scanner(System.in);  
System.out.println("Enter the 1st String: ");  
String a = sc.nextLine();  

System.out.println("Enter the 2nd String: ");  
String b = sc.nextLine();  

// 1. Append a & b  
a = a+b;  

// 2. Store initials of 'a' string in 'b'  
b = a.substring(0, a.length()-b.length());  

// 3. Store initials of 'b' string in 'a'  
a = a.substring(b.length());  

System.out.println("The new swapped 1st String: " + a );  
System.out.print("The new swapped 2nd String: " + b );  
  
}
```
