## Concept
1.  1+2+4+5 = 12  
2. 1+2+3+4+5 = 15     
3. 15-12 = 3 
4. Goes for every missing value in increasing formula 
5. Here you have to identify the missing element value.
```JAVA
public static void missingno(){  
// Array input       
Scanner sc = new Scanner(System.in);  
System.out.println("Enter the Elements to store: ");  
int num = sc.nextInt();  

System.out.println("Enter the elements");  
int [] arr = new int[num];  

for (int i = 0; i<num ; i++) {  
arr[i] = sc.nextInt();  
}  
// ------------------------------------------------------  
int sum = 0;  
for (int i = 0; i < arr.length ; i++) {  
sum += arr[i];  
}  
System.out.println("The Sum of the Given Array: "+ sum);  
  
// -------------------------------------------------------  
int sum1 =0;  
for (int j = 0; j <=num+1; j++) {  
sum1 += j;  
}  
System.out.println("The array sum which contains every element: "+sum1);  
// ---------------------------------------------------------  
System.out.println("The Missing Element is: "+ (sum1 - sum));  
  
    }
```
