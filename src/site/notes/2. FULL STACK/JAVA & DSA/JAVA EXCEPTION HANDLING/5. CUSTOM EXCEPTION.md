#java #Object_Oriented_Programming 
- To make custom exception 
	1. Create new **CLASS FILE**
	2. **`extends`** the class with the **SUPER CLASS** of all Exception i.e. **`Exception`** class
	3. Add the **`constructor`**
```Java
public class SomeException extends Exception{
	public SomeOneException(String message){
		super("hello error");
	}
}
```
