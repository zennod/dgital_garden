# DATABASE SYSTEM CONSIST OF 2 THINGS. 
 - ## DATA-BASE -  
	 - ==It's a **Collection of RELATED DATA**.==
	 - ==**RELATED meaning the data is inter-related information present on a specific server.**==
	- The data present here is **STRUCTURED & UNSTRUCTURED** in nature.

- ## DBMS -
	- ==**DBMS is a software which provides the collection of operations to manage the database system.**==
	- The operation includes **INSERTION, DELETION & UPDATION.**
	- The goal of DBMS is to store & retrieve database information in an CONVENIENT & EFFICIENT way.

 - ## DATABASE SYSTEM - 
	 - ==Database System are used to manage information for the large enterprises.==
	 - **MANAGEMENT OF DATA INVOLVES.**
		- *Storage of Information.*
		- *Manipulation of Information.*
		- *Safety of Information from the unauthorized access & System Crashes.*

# TO LIST TABLES PRESENT IN THE DATABASE
```SQL 
select * from information_schema.table;
```
