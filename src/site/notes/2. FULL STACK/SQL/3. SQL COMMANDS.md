## COMMON COMMANDS
1. **SELECT** - Select a specific data from the table 
2. **INSERT** - Insert data into the table 
3. **DELETE** - Delete data of the table 
4. **UPDATE** - Update/Modify data of the table
5. **DROP** - Delete the whole table
6. **UNION** - Combines the data by combining queries. 
7. **WHERE** - Filter based on the specific condition
8. **AND/OR/NOT** - Filter records (rows) based on multiple conditions
9. **ORDER BY** - Sort the records of the table in ascending/descending order

SELECT Userid, Name FROM User

SELECT * FROM User WHERE Country='RU' AND Name='John';

# 8. JOINS 
## INNER JOIN 
- Inner Joins is based on the common attributes(columns) present in different tables (*i.e. **'id'** which can be same in different table for the same person*)
- It's like *table A* **INTERSECTION** *table B*
```SQL
SELECT * FROM info <table_name_A> INNER JOIN <DB_NAME.table_name_B> on <common attribute>;

-- To access a specific row to join 
-- General form = <DB_NAME.TABLE_NAME.COL_NAME>
-- Example

SELECT * FROM info INNER JOIN students.marks ON student.info.id = student.marks.id;
```
- **`ON`** - Meaning 'on what basis' you want join the table
***
***
## INNER LEFT JOIN
- SAME AS INNER JOIN.
- It displays whole information of both the table & also display the **`null`** values(if exist) of the LEFT MENTIONED table in the query (i.e. marks table). 
```SQL
SELECT * FROM info LEFT JOIN students.marks ON student.info.id = student.marks.id;
```
***
***
## INNER RIGHT JOIN
-  It displays whole information of both the table & also display the **`null`** values (if exist) of the RIGHT MENTIONED table in the query (i.e. info table). 
```SQL
SELECT * FROM info RIGHT JOIN students.marks ON student.info.id = student.marks.id;
```
***
***
## FULL OUTER JOIN
- It combines every values of the tables mentioned
```SQL
SELECT * FROM info FULL OUTER
JOIN students.marks ON student.info.id = student.marks.id;
```
