#SQL #database #mysql 
# PRIMARY KEY 
- It's a *column* that **UNIQUELY** identify each row
- There exist only **ONE** PRIMARY KEY
- Also, **NOT NULL** 
- Example - **`id`**, **`emp_no`**, **`roll_no`**
***
***
# FOREIGN KEY 
- It's a *column* that refers to the PRIMARY KEY.
- Can be **MULTIPLE** foreign key.
- Can be **DUPLICATE** & **NULL**
