#SQL  #database #mysql 
# UPDATE 
> [!important]
>  Here,  it's **mandatory** to *apply the condition* or else it'll apply the **changes** made to *all the rows*.

- First set the SAFE MODE to 0 (off) - 
```SQL 
SET SQL_SAFE_UPDATES=0;
```

```SQL 
UPDATE table_name SET col_1 = val_1 WHERE condition;
```
