#SQL #database #mysql 

- It refers to the **SPECIFIC RULES** in a TABLE.
***
1. **NOT NULL** 
	- If we add **NOT NULL** while defining a column. 
	- There we can't store *NOT NULL*.
	- **`col1 data_type NOT NULL`**

2. **UNIQUE** 
	- If we add **UNIQUE** while defining a column. 
	- There we have to store only **UNIQUE** value.
	- **`col1 data_type UNIQUE`**

3. **PRIMARY KEY**
	- If we add **PRIMARY KEY** while defining a column. 
	- It makes a column *UNIQUE* & *NOT NULL*
	- **`id data_type PRIMARY KEY`** 
	- **`PRIMARY KEY(col1_name)`** or **`PRIMARY KEY(col1_name, col2_name)`** 

4. **FOREIGN KEY**
	- If we add **FOREIGN KEY** while defining a column. 
	- It prevent actions that would *DESTROY* links between tables.
	- **`FOREIGN KEY (new_table_FOREIGN_KEY) references existing_table(PRIMARY_KEY)`**

5. **DEFAULT** 
	- If we add **DEFAULT** while defining a column. 
	- It SETs the **DEFAULT VALUE** to a column.
	- **`col data_type DEFAULT value`**

6. **CHECK**
	- If we add **CHECK** while defining a column. 
	- It *LIMITS THE VALUES* allowed in a column
	- **`CONSTRAIN col_to_be_checked CHECK condition`** 
	- **`col data_type condition`**
