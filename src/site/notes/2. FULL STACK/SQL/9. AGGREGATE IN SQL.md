#SQL #database #mysql 

- Used to get AGGREGATION of a ROW. 
# TYPES OF AGGREGATE FUNCTIONs 
## `COUNT()`

```SQL
SELECT COUNT(value)
FROM table
```
***
## `MAX()`

```SQL
SELECT MIN(value)
FROM table
```
***
## `MIN()`

```SQL
SELECT MIN(value)
FROM table
```
***
## `SUM()`

```SQL
SELECT SUM(value)
FROM table
```
***
## `AVG()`

```SQL
SELECT AVG(value)
FROM table
```
