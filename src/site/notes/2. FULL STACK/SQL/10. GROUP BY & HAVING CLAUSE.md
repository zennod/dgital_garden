# GROUP-BY 
- It refers to *fetch values* in **GROUP**.
- It's mostly used with the *[[9. AGGREGATE IN SQL \| AGGREGATE]]* function.
- The many columns you write in the **`SELECT`** statement has to written in the **`GROUP BY`** statement.
```SQL
SELECT col1, agg(col2)
FROM table 
GROUP BY col1;
```

```SQL 
SELECT city, count(roll_no)
FROM student
GROUP BY city;
```

# HAVING 
- The **HAVING** clause works same as [[7. SELECT, SELECT DISTINCT, WHERE IN SQL \| WHERE ]] clause 
- Used when applied **GROUP BY** clause.
```SQL 
SELECT city, count(roll_no)
FROM student
GROUP BY city;
HAVING MAX(marks) > 90;
```
