#SQL 
# ORDER BY
- In databases the data is not sorted/ordered.
- Used to **SORT** data in *ASCENDING / DECENDING* order.
- By DEFAULT **`ORDER BY`** is sorted in **ASCENDING** Order.

```SQL
SELECT "col_1", "col_2"...,"col_n" 
FROM table_name
WHERE condition
ORDER BY "col" ASC/DESC;
```

## EXAMPLE 
```SQL 
SELECT *
FROM student
ORDER BY marks ASC;
```

# LIMIT
- Sets a **LIMIT** on the *number of* **ROWS** to be *returned*.
```SQL
SELECT "col_1", "col_2"...,"col_n" 
FROM table_name
LIMIT number;
```
## EXAMPLE 
```SQL 
SELECT * 
FROM student
LIMIT 3;
```
