#devops #YAML
# VARIABLE - 
- In YAML, the **`KEY : VALUE`** pair the **VALUE** is known as **VARIABLE**. 
- And the Variable can be of many types.
```YAML
Name: Xerxeus 
# KEY : VALUE & VARIABLE

# STRING VARIABLE - IN ""/''
Name: Xerxeus
fruit:"mango"
job: 'SDE'
```
***
***
# MULTI LINE VARIABLE - 
``` YAML
# MULTI LINE VARIABLE
bio: |
Hello My name is XerXeus Borth.
Welcome to my Space.

# Code written in MULTIPLE LINES
# But When Parsed will be viewed in ONE SINGLE LINE
message: >
This Message
will be
visible as a
ONE SINGLE LINE
# The above is same as this - 
message:This Message will be visible as a ONE SINGLE LINE
```

# MORE DATA TYPES - 
```YAML 
# Integer 
number : 43324

# Float 
marks : 67.52

# Boolean 
Task_Done: No 
# No represents FALSE. Also, You can write n,N,false,False,FALSE
Task_Done : Yes  
# No represents TRUE. Also, You can write y,Y,true,True,TRUE
```

# SPECIFY DATA TYPE - 
- You can also explicitly tell the YAML the Data Type.
- *SYNTAX -* **`KEY : !!DATATYPE VALUE`** 
```YAML 
# Integer 
zero: !!int 0 
number : !!int 20
negative_number : !!int -34
binary_number : !!int 0b11001
octal_number : !!int  06457
hexa_number : !!int  0x45
commaValue_number : !!int +4_50_000 # 4,50,000
Exponential_number : 6.023E56 

# Float 
marks : !!float 56.45
infinite : !!float .inf # Infinite Number 
not_a_number : .nan #NaN


# String 
name : !!str Caesar 

# Boolean
Bool_Val: !!bool False

# Null 
Debt : !!null Null # Also, can be written as null,NULL, ~

#date & time 
date: !!timestamp 20-10-2010
```
