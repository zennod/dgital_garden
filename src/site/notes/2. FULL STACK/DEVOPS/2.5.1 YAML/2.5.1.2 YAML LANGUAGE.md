#devops #YAML 

- It stands for **YAML AIN'T MARKUP LANGUAGE** 
- It's also **CASE - SENSITIVE** 
- It's not a *programming language* a **DATA FORMAT** used to **EXCHANGE DATA** *(similar to XML/JSON)*
- In YAML, you can only store *DATA but not COMMAND*.
- YAML is a *collection of one or more* **DOCUMENTs**

> [!question]
> Q] *Why's that the YAML is not YET ANOTHER MARKUP LANGUAGE?*
> ANS - Because markup language stores documents. But in **YAML you store DOCUMENTs with DATA** *(objects)*

***
***
# DATA SERIALIZATION 
- If you want to use the **DATA** in different medium of a single format. There comes the concept of **DATA SERALIZATION**.

> [!note]
> *Serializable is basically a process of converting the **data objects(code + data) into series of byte** that saves the state of this object in a form which is easily transmittable.*
> De-Serialization is the *reverse process of converting complex chunks of data into object*

Another Definition - 
1. Translation of Object (Code + Data) into stream of bytes that saves the state of this object in a form that is transmittable.
2. Using Serialization, data can be converted into code and code can be converted into data again.

# USAGE -
1. Configuration File - DOCKER / KUBERNETES, etc.
2. Logs, Cache data. 
# BENEFITS -
- Simple and easy to read 
- Easy Syntax - ***Indentation is Important.***
- Easily **convertible** to JSON & XML.
- More powerful when *representing complex data.*
- Parsing *(i.e. Reading the Data)* is easy

# EXAMPLEs - 
## KEY VALUE DATA TYPE - 
- Just a basic `KEY:VALUE` pair
``` YAML 
"first_name": "Xerxeus"
"last_name": "Borth"
1:"roll no"
```
## LIST DATA TYPE - 
- The LIST is represented by the `-` symbol
```YAML 
- ball
- Ball

# THE above both are different in nature, as YAML is case-sensitive.

- bat 
- stump
```

## DOCUMENT SEPERATION -
- The ***`---`*** three lines are used to tell the YAML that - It's a different documents.
- To end the Document use **`...`** three dots
``` YAML 
# KEY VALUE PAIR
"first_name": "Xerxeus"
"last_name": "Borth"
1:"roll no"

--- #SEPERATOR

# LIST Data type
- ball
- Ball
# THE above both are different in nature, as YAML is case-sensitive.
- bat
- stump

--- #SEPERATOR

# KEY VALUE + LISTS
"cities" :
 - New York
 - Jersey
 - Texas
 - Kentucky 
---
"games": [Halo, GTA5]
---
{Name: "Caesar", age:22}

... #DOCUMENT END 
```
