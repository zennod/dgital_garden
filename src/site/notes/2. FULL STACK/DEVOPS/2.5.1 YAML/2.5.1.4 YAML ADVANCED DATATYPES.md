#devops #YAML 
# SEQUENCE 
- Earlier, we stored data in list.
- So, the list is a **SEQUENCE** kind of datatype.
```YAML 
"student": !!seq 
 - marks
 - name 
 - roll_no

# Also, can be written in different forms  
"student" : [marks, name, roll_no]
```
***
***
# SPARSE SEQUENCE 
- It represents that some of the **KEYS WILL BE EMPTY**
```YAML 
"empty_list": 
 - One 
 - Two 
 - 
 - Null 
 - Five
```

# NESTED SEQUENCE 
``` YAML 
cars:

   - Null
```

# MAPS - 
- The *KEY : VALUE* pair is called as **MAPS**
``` YAML 
!!map
```
## NESTED MAPS
- Map within the map 
```YAML 
name : "Xerxeus Borth"
info: 
 age: 22
 role: student

# same as 
name : "Xerxeus Borth"
info: {age: 22 , role: student} 
 
```
***
***
# PAIRS -
- It represents that the **KEYS** might have duplicate **VALUES**
``` YAML
pairs : !!pairs
 - job: student
 - job: teacher 

# same as 
pairs : !!pairs [job: student, job: teacher]
```
- This will be an *ARRAY* of *HASH TABLEs.*
***
***
# SET - 
- It'll only contain **UNIQUE VALUES**
```YAML 
name: !!set 
 ? Xero
 ? Hero : Actor
 ? Kingo
```

# DICTIONARY 
- We use dictionary, when we need the whole[[2. FULL STACK/DEVOPS/2.5.1 YAML/2.5.1.4 YAML ADVANCED DATATYPES#SEQUENCE \| SEQUENCE]] to be used as a **VALUE** of the **KEY**.
```YAML 
people: !!omap 
 - person_1:
  name: "Xerxeus Borth"
  age: 22
  weight: "78kg"
 - person_2:
  name: "Caesar"
  age: 23
  weight:"60kg"
```

# REUSING PROPERTIES 
- To use similar properties for different purpose we use **ANCHORS.**
- `&property_name` should be used at the *main property*.  
- `<<: *property_name` should be entered while *reusing property.*
- If you enter any property which is already added than it'll be changed as new.
```YAML 
likes : &reuse
 fruits: pineapple
 car : GTR34

person_1:
 name: Xerxeus
 <<: *reuse
 
person_2:
 name: Caesar
 <<: *reuse
 car: supra MK4
```
