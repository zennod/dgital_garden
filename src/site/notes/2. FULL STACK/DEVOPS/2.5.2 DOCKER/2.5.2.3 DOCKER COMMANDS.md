- Run the server or any service locally using docker port.
**`docker run -d -p local_port:docker_port service_name`**
- *Example* - **`docker run -d -p 8080:80 nginx`**

# CREATE DOCKER IMAAGE  
- Creating personal docker image. *Create a empty folder & also create docker_file and write the commands*
```bash 
FROM base_os 
MAINTAINER your_name 
RUN command
CMD ["enter","commands","in", "array"]
```
- **Example** - 
```bash 
FROM ubuntu
MAINTAINER Xerxeus Borth
RUN sudo apt-get update
CMD ["echo", "Hello it's my own build docker file"]
```

- Next, you got to BUILD the IMAGE. 
**`docker build -t image_name:version path_of_docker`**

- Also, create a docker hub account, if you want to share your created image.
- Then, use **`docker login`** to log into your account.
