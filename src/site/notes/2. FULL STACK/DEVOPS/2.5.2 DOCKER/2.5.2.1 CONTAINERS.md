# WHAT ARE CONTAINERs?? 
1. *The code, DB, Libraries, etc all the requirement is stored in a* **CONTAINER** *& it's share to the peers.*
2. **Docker is a tool to create, manage, scale containers.**

> [!info]
> If you containerized a docker in **WINDOWS HOST**; It won't run in a **LINUX HOST**
> In other words, The *container runs* in the **SAME ARCHITECTURE** host in which the *container is created.*

> [!tip]
> *For WINDOWS* - **DOCKER DESKTOP** + **WSL**
> *For MAC* - **DOCKER DESKTOP** 
> *For LINUX* - **CLI**
