#devops 
# WHAT IS SDLC ??
- *SDLC* is a process which is followed by the industry to **DESIGN, DEVELOP & TEST** *high quality product.*
![dd 1.png](/img/user/_resources/dd%201.png)
***
*** 
# PHASES OF SDLC
# 1. PLANNING  
- It involves the *Planning & Requirement* needed in the **PROJECT**.
# 2. DEFINING 
- Here, You need to clearly define the whole *PLANNING & REQUIREMENTS* in terms of **OFFICIAL DOCUMENTS**.
- In the *DOCUMENT*, all the data is written which is collected by the BA.
# 3. DESIGNING  
- Here, the designing is done in 2 types: -
	1. **HIGH LEVEL DESIGN** - Here, the senior developer will *design high level requirements* the as per his/her needs. 
	2. **LOW LEVEL DESIGN** - Here, the senior developer will *design low level requirements* as per his/her needs. Such as - Modules, Functions, etc

***
# MAIN PHASES 
- The Devops Engineer plays vital role in the below phases
# 4. BUILDING 
- This refers to the DEVELOPING of the PROJECT.
- Once, *Planning & Requirement is gathered and Documents is ready with the HIGH/LOW LEVEL DESIGN made by the senior developer.*
- Then, the **DEVELOPMENT** will begin.
- Once, the *code is written as per the requirement*; It's pushed to a common location called **GIT**.
# 5. TESTING 
- This refers to the **TESTING** of the code which is **PUSHED** on the **SERVER**. 
- This is done to verify that the code is running in every machine. 
- *To deliver the high quality end product to the Customer.*
# 6. DEPLOYMENT 
- After, the **TESTING** phase the application is promoted to the **PRODUCTION** *server* which is used by the **CUSTOMER**.
